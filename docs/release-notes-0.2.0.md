# Kursor Theme 0.2.0

Живые эффекты вокруг курсора без подмены системного курсора и стилизованное выделение области.

## Что нового

- **Блоки функций**: эффекты, пресеты, выделение и горячие клавиши отключаются отдельно.
- **8 новых пресетов**: Cyberpunk, Synthwave, Matrix, Vaporwave, Arcade, Hacker, Graffiti, Tattoo — всего 12.
- Исправлена шапка настроек: подзаголовок больше не перекрывает «Сбросить».
- Окно настроек центрируется на основном мониторе и открывается поверх остальных окон.
- Портативная сборка и установщик (per-user, без прав администратора).

## Установка

- `KursorThemeSetup.exe` — установщик для текущего пользователя.
- `KursorTheme-portable.zip` — распаковать и запустить `KursorTheme.exe`.

Горячие клавиши: `Ctrl+Alt+E` — эффекты, `Ctrl+Alt+S` — выделение, `Ctrl+Alt+O` — настройки.
