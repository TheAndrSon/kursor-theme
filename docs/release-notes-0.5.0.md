# Kursor Theme 0.5.0

Живые эффекты вокруг курсора без подмены системного курсора и стилизованное выделение области.

## Что нового

- **Базовые настройки и пресет Base**: свечение 12 px / 20% / 15% / 1.00×,
  шлейф 240 мс / 3.5 px / 70%, волна 30 px / 340 мс / 2.0 / 3 кольца,
  частицы 15 / 450 / 1100 / 600 мс / 2.0 px.
- **Смена стиля меняет только форму**: длина, толщина, количество, скорость, радиус и цвет
  остаются вашими. Стили не перезаписывают числовые настройки.
- **9 стилей шлейфа**, **8 стилей частиц** (включая код Matrix, брызги, глитч, звёзды, пузыри)
  и **8 стилей волны**.
- **Нет мерцания** при выборе стилей и пресетов: интерфейс обновляется на месте.
- Окно настроек больше не always-on-top: поднимается, пока активно, и уходит за браузер
  при клике вне него.
- Слой эффектов остаётся выше других topmost-окон и видим в полноэкранных вкладках
  браузеров/веб-видео. В играх по-прежнему скрывается настройкой.
- Выделение и горячие клавиши по умолчанию **выключены**.
- Исправлен скролл и накопление пустого отступа сверху.

## Установка

- `KursorThemeSetup.exe` — установщик для текущего пользователя, без прав администратора.
- `KursorTheme-portable.zip` — распаковать и запустить `KursorTheme.exe`.

Горячие клавиши (после включения блока «Горячие клавиши»): `Ctrl+Alt+E` — эффекты,
`Ctrl+Alt+S` — выделение, `Ctrl+Alt+O` — настройки.

Поверх окон, запущенных от администратора, эффекты не рисуются (UIPI) — для этого
запустите приложение от имени администратора.
